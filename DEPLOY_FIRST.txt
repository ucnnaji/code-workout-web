4. In Render keep/set:

   SUPABASE_SECRET_KEY
   PUBLIC_ORIGIN
   PII_ENCRYPTION_KEY
   ADMIN_TOKEN
   COMPENSATION_ADMIN_TOKEN
   OPENAI_API_KEY
   OPENAI_MODEL

   JUDGE0_URL=https://ce.judge0.com (or your approved Judge0-compatible service)

6. PII_ENCRYPTION_KEY must decode to exactly 32 random bytes.
7. For remote student self-enrollment, set LIVE_COLLECTION_ENABLED=true and keep the saved study configuration deliveryMode set to remote.
8. Render liveness: /healthz. Setup diagnostics: /health. Strict readiness: /readyz.
9. Deploy latest commit after environment changes.
10. After deploy, open the public URL in a private/incognito window and verify that a student can consent, choose a Participant ID/language, generate a Private Access Key, and start Session 1.
